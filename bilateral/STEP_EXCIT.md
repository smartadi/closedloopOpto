# AL_0048 — excitatory (LEFT) long-duration step responses

Trial-averaged %dF/F at the **data-derived activation site** for every left-hemisphere
constant-step condition with bout duration >= 0.5 s, within-bout command SD <
0.05 V, n >= 5 and saved widefield. Generated by `step_response.py`; the
session inventory it draws on is `AL0048_CATALOG.md`.

Site = extremum of the smoothed whole-step minus (-0.5 -> 0 s) dF/F map inside the
stimulated hemifield; ROI = 20x20 px around it. `early` is where the
0.03-0.15 s map peaks and `split` their distance; when split > 25 px the early
locus is a separate response and is traced separately (see the figure).
Peak/plateau/offset are read off
the TRIAL-MEAN trace (plateau = last 25% of the step; offset = min within
1.0 s of step end). `pre-sd` is the trial-mean SD before onset — the noise floor.

**`jump`** = fraction of the peak already reached in the FIRST frame after onset. A row is
flagged **ARTIFACT** when peak > 20 % or jump > 0.7: photostim light leaking into
the camera reproduces the command waveform (square, one-frame edges, ringing) instead of a
calcium transient. Flagged rows are kept in the table and in the per-condition figure but
excluded from the overlay — they measure the laser, not the cortex.
