\sectionbar{Introduction}
\begin{textbox}
Testing what mesoscale cortical dynamics \emph{cause} requires shaping them, not just perturbing them.
We built a closed loop that holds one cortical region at a target with optogenetic inhibition.
\begin{itemize}
  \item How well does feedback hold activity at the target?
  \item Which brain states make it harder -- and what does the error left under control tell us about state?
\end{itemize}
\end{textbox}
\gap
\sectionbar{Results}
\begin{resultbox}{1}{A real-time imaging + optogenetics control loop}
\fig[0.74\linewidth]{\figonepath}
\begin{itemize}
  \item Wide-field GCaMP imaging at 35\,Hz; the output is $\Delta F/F$ in a kernel beside a
        red-laser inhibition spot (a, b).
  \item Loop latency 24\,ms median, $\le$\,47\,ms -- inside one frame (c, d).
  \item Controller: PI feedback ($K_p, K_i$) plus a feedforward gain $K_r$ (e).
\end{itemize}
\end{resultbox}
\gap
\begin{resultbox}{2}{Trial-averaged responses are near-linear; single trials vary with state}
\fig{Figure2.pdf}
\begin{itemize}
  \item Suppression scales linearly with laser power (B; $R^2 = 0.73$--$0.97$, 4 sessions, 3 mice);
        a low-order LTI model predicts held-out trial averages (C, D; median $R^2 = 0.85$).
  \item Models transfer only partly between sessions (E) $\Rightarrow$ a rough feedforward gain, corrected by feedback.
  \item Single-trial variability follows state: $0.58\times$ in high motion, $2.35\times$ in high
        absolute $\delta$ power -- stimulus-free activity does the same (G).
\end{itemize}
\end{resultbox}
\end{minipage}\hfill

\begin{minipage}[t]{0.32\linewidth}\vspace{0pt}
\begin{resultbox}{3}{Feedback tracks the target better and cuts variability}
\fig[0.96\linewidth]{Figure3.pdf}
\vspace{-0.2em}
{\smallsize Target $-5\%\,\Delta F/F$ for 3\,s; \textcolor{clblue}{\textbf{closed loop}} and
\textcolor{olred}{\textbf{open loop}} (feedforward only) randomly interleaved. 15 sessions, 4 mice.\par}
\begin{itemize}
  \item Tracking error (RMSE) $-23\%$ over the stimulus (ratio 0.77, $p = 5.8\times10^{-8}$),
        lower in \textbf{all 15 sessions}; $-32\%$ at steady state (H).
  \item Across-trial variance $-42\%$ (0.58, $p = 6.3\times10^{-6}$); the ratio is 1 before and
        after stimulation $\Rightarrow$ \textbf{disturbance rejection} (D, E, I).
  \item Still 13\% better than the best \emph{fixed} input chosen in hindsight ($p = 6.5\times10^{-4}$),
        so the gain is feedback, not calibration.
\end{itemize}
\end{resultbox}
\gap
\begin{resultbox}{4}{Controller performance is brain-state dependent}
\fig[0.92\linewidth]{Figure4.pdf}
\begin{itemize}
  \item Transient error is set by the initial deviation (unique $R^2 = 0.53$); steady-state error
        by large, slow absolute 1--4\,Hz power (B, C).
  \item \textbf{Movement:} open-loop error rises, closed-loop error stays flat -- feedback removes
        a larger share of the error the more the mouse moves ($-13\%$ per SD, $p = 0.0023$) (D).
  \item \textbf{Slow $\delta$ fluctuations:} closed-loop error rises in all 15 sessions
        ($p = 7.1\times10^{-4}$) -- feedback does not hold the target as $\delta$ power grows (D).
  \item A contralateral$\to$ipsilateral model (held-out $R^2 = 0.76$) estimates each trial's
        disturbance; closed loop leaves 0.58 of its energy ($p = 1.3\times10^{-4}$, 11 sessions) (E--G).
\end{itemize}
\end{resultbox}
\end{minipage}\hfill

\begin{minipage}[t]{0.32\linewidth}\vspace{0pt}
\begin{resultbox}{5}{Moving target: feedback cuts error, preview cancels lag}
\fig{Figure5.pdf}
{\smallsize 1\,Hz sinusoidal target; preview shifts the reference ahead by the cortical delay
(5 samples, 143\,ms). OL, OL$+$preview, CL, CL$+$preview interleaved (Mouse 3, 3 sessions).\par}
\begin{itemize}
  \item Feedback halves across-trial variance (11.8 $\to$ 5.8\,$(\%\Delta F/F)^2$) and lowers
        median RMSE 3.59 $\to$ 2.26 (E--G).
  \item Preview cancels the phase lag (OL $71^\circ \to 16^\circ$, CL $46^\circ \to 2^\circ$),
        as the lookahead predicts (H).
  \item Same direction in all 3 sessions (I--K; $n = 3$, no tests).
\end{itemize}
\end{resultbox}

\sectionbar{Conclusions}
\begin{textbox}
\begin{itemize}
  \item Near-linear, time-invariant trial-averaged dynamics are enough to design a controller
        that \textbf{holds regional cortical activity at a target}, better than open loop in every
        session and mouse.
  \item \textbf{Brain state sets what feedback can cancel:} it absorbs the error that comes with
        movement, but error still grows with slow $\delta$-band fluctuations.
  \item The error left under control is \textbf{a readout of brain state}, and part of the
        disturbance is predictable from the opposite hemisphere.
  \item Feedback and preview fix different failures; together they track a moving target.
\end{itemize}
