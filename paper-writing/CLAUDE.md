## Reviewer / Style Notes (from PAPER.md §Stuff from CLAUDE)
Key issues raised:

1. **Linearity claim too broad**: The paper tests linearity using peak ΔF/F vs amplitude only. Should either show full waveforms superimpose after normalization, OR soften to "peak response scales approximately linearly." Critical because controller design assumes LTI dynamics.

2. **Step response paragraph internal tension**: Writes "approximated with linear system response reaching steady state" then notes "trajectories do not converge to fixed equilibrium within window." Resolve: state window is too short OR narrow the claim.

3. **Variance-convergence paragraph**: The CLT argument does not establish zero-mean disturbances (a drifting process would also show shrinking batch-variance). Rephrase: show batch *mean* stabilizes across batch sizes.

4. **"Three independent sessions" for linearity**: n=3 across unknown mice. Explain selection criterion or add sessions.

5. **"Stimulation onset did not affect trial-to-trial variance"**: Clarify this is OL only; quantify.
